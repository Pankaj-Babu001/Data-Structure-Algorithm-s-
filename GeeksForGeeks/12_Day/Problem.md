## 🧩 Problem Description
Given an array `arr[]` that contains both positive and negative integers (and potentially `0`), find the maximum product that can be obtained from any contiguous subarray.

## 📌 Examples

**Example 1:**
> **Input:** `arr[] = [-2, 6, -3, -10, 0, 2]`
> **Output:** `180`
> **Explanation:** The subarray `[6, -3, -10]` gives the maximum product: $6 \times (-3) \times (-10) = 180$.

**Example 2:**
> **Input:** `arr[] = [-1, -3, -10, 0, 6]`
> **Output:** `30`
> **Explanation:** Subarray `[-3, -10]` gives $30$.

---

## 📐 Constraints
- $1 \le arr.size() \le 10^6$
- $-10 \le arr[i] \le 10$
