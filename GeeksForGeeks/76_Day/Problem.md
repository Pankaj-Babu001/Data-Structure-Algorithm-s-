## 🧩 Problem Description
Given a number in the form of an array `num[]`, find the **next smallest palindrome** that is strictly larger than the given number.

## 📌 Examples

**Example 1:**
> **Input:** `num = [2, 3, 5, 4, 5]`
> **Output:** `[2, 3, 6, 3, 2]`
> **Explanation:** The number is 23545. The next palindrome is 23632.

**Example 2:**
> **Input:** `num = [9, 9, 9]`
> **Output:** `[1, 0, 0, 1]`
> **Explanation:** 999 → 1001.

---

## 📐 Constraints
- $1 \le N \le 10^5$
- $1 \le num[i] \le 9$
