## 🧩 Problem Description
Given `n` dice, each with `m` faces (numbered 1 to `m`), find the number of ways to achieve a total sum `x` when all the dice are thrown simultaneously.

## 📌 Examples

**Example 1:**
> **Input:** `m = 6, n = 3, x = 12`
> **Output:** `25`
> **Explanation:** There are 25 distinct combinations of face values that sum up to 12.

**Example 2:**
> **Input:** `m = 2, n = 3, x = 6`
> **Output:** `1`
> **Explanation:** The only way to get a sum of 6 with 3 dice of 2 faces each is $[2, 2, 2]$.

---

## 📐 Constraints
- $1 \le m, n, x \le 50$
