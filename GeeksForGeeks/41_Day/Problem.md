## 🧩 Problem Description
Given a string `s` representing a non-negative integer, find the lexicographically largest string that can be obtained by performing **at most one** swap of two characters in the string.

## 📌 Examples

**Example 1:**
> **Input:** `s = "768"`
> **Output:** `"867"`
> **Explanation:** Swapping '7' (1st pos) and '8' (3rd pos) gives the largest result "867".

**Example 2:**
> **Input:** `s = "333"`
> **Output:** `"333"`
> **Explanation:** Any swap results in the same string.

**Example 3:**
> **Input:** `s = "98368"`
> **Output:** `"98863"`
> **Explanation:** Swapping the first '3' with the last '8' gives "98863".

---

## 📐 Constraints
- $1 \le s.length() \le 10^5$
- String consists of digits '0'-'9'.
