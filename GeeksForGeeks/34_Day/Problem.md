## 🧩 Problem Description
Given an array `arr[]` of non-negative integers representing the height of blocks, calculate how much water can be trapped between the blocks during the rainy season. The width of each block is 1.

## 📌 Examples

**Example 1:**
> **Input:** `arr[] = [3, 0, 1, 0, 4, 0, 2]`
> **Output:** `10`
> **Explanation:** Total water trapped is 10 units.

**Example 2:**
> **Input:** `arr[] = [3, 0, 2, 0, 4]`
> **Output:** `7`
> **Explanation:** Total water trapped is 7 units.

**Example 3:**
> **Input:** `arr[] = [1, 2, 3, 4]`
> **Output:** `0`
> **Explanation:** No water can be trapped as there is no height bound on both sides.

---

## 📐 Constraints
- $2 \le arr.size() \le 10^5$
- $0 \le arr[i] \le 10^3$
