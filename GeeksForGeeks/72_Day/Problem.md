## 🧩 Problem Description
Given two **sorted** arrays `a[]` and `b[]`, each possibly containing duplicate elements, return the elements in the intersection of the two arrays in sorted order.

**Note:** The intersection should contain only **distinct** common elements present in both arrays.

## 📌 Examples

**Example 1:**
> **Input:** `a = [1, 1, 2, 2, 2, 4], b = [2, 2, 4, 4]`
> **Output:** `[2, 4]`
> **Explanation:** 2 and 4 are the only common elements. We return them once.

**Example 2:**
> **Input:** `a = [1, 2], b = [3, 4]`
> **Output:** `[]`
> **Explanation:** No common elements.

---

## 📐 Constraints
- $1 \le a.size(), b.size() \le 10^5$
- $-10^9 \le a[i], b[i] \le 10^9$
