## 🧩 Problem Description
Given two arrays `a[]` and `b[]`, find the **Union** of both arrays. The union consists of all distinct elements present in either array. If an element appears multiple times, it should only be included once in the result.

## 📌 Examples

**Example 1:**
> **Input:** `a[] = [1, 2, 3, 2, 1], b[] = [3, 2, 2, 3, 3, 2]`
> **Output:** `[1, 2, 3]`
> **Explanation:** The distinct elements present in both arrays are 1, 2, and 3.

**Example 2:**
> **Input:** `a[] = [1, 2, 3], b[] = [4, 5, 6]`
> **Output:** `[1, 2, 3, 4, 5, 6]`

---

## 📐 Constraints
- $1 \le a.size(), b.size() \le 10^6$
- $0 \le a[i], b[i] \le 10^5$
