## 🧩 Problem Description
Given a string `s`, remove all the spaces from the string and return the modified version. The order of non-space characters must be preserved.

## 📌 Examples

**Example 1:**
> **Input:** `s = "g eeks for ge eeks"`
> **Output:** `"geeksforgeeks"`
> **Explanation:** All spaces are removed.

**Example 2:**
> **Input:** `s = "abc d "`
> **Output:** `"abcd"`

---

## 📐 Constraints
- $1 \le \text{s.length()} \le 10^5$

---

## ⏱️ Expected Complexities

| :--- | :--- |
| $O(N)$ | $O(1)$ (In-place) |
