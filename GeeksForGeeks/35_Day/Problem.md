## 🧩 Problem Description
Given an array `arr[]` of positive integers, find the length of the **longest contiguous subarray** that contains at most **two distinct** integers.

## 📌 Examples

**Example 1:**
> **Input:** `arr[] = [2, 1, 2]`
> **Output:** `3`
> **Explanation:** The entire array contains only two distinct integers (2 and 1).

**Example 2:**
> **Input:** `arr[] = [3, 1, 2, 2, 2, 2]`
> **Output:** `5`
> **Explanation:** The longest subarray is `[1, 2, 2, 2, 2]` with length 5.

---

## 📐 Constraints
- $1 \le arr.size() \le 10^5$
- $1 \le arr[i] \le 10^5$
